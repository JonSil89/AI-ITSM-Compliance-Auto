# AI Boundary Model

## Principle

AI assistance is advisory in this proof-of-concept.

The repository may use AI-related concepts for documentation support and future ranking ideas, but the current CI path does not depend on autonomous AI behavior.

## Allowed in this POC

- documentation drafting
- log explanation
- audit report summarization
- test idea generation
- future ranking experiments

## Not allowed in this POC

- autonomous deployment
- automatic approval of compliance status
- bypassing human review
- treating generated reports as certification
- using environment-specific confidential data without approval

## Current status

RankLSTM is treated as a legacy / research-inspired component. It is not the active compliance validation path.
